# Demo Flow

## Recommended Sequence (8-10 minutes)

1. Open dashboard and show overall metrics.
2. Show invoice table with mixed overdue and non-overdue records.
3. Run deterministic overdue processing.
4. Show escalation groups and legal escalation panel.
5. Generate AI preview for one overdue invoice.
6. Show validation metadata and stored preview.
7. Open Delivery page and approve email.
8. Trigger dry-run send and show status change.
9. Open Orchestration page, run workflow, show pause/resume logic.
10. Show trace timeline and audit logs.

## Evaluator Talking Points

- Deterministic logic controls business truth.
- AI is constrained to communication rendering.
- Unsafe outputs are rejectable by validation.
- Human approval is mandatory before delivery.
- Dry-run is default-safe operational mode.
- LangGraph orchestrates existing modular services.
